# 路径规划类任务澄清参考

适用场景：城市配送、TSP 单实例/多实例求解、危化品运输、多车路径规划（VRP/CVRP/VRPTW）、多仓库配送等。

读完数据后，将你对以下每条约束的理解整理成确认问题，逐一向用户确认，**不得因"数据已有"而跳过**。

---

## 需要确认的约束

### 优化目标
- 优化目标是最小化总行驶距离、总时间、总成本，还是多目标？
- 多目标时的优先级或权重如何？
- TSP 多实例场景：是否需要为所有实例都提供有效路线（任一缺失则得 0 分）？

### 车辆与资源约束
- 车辆数量是固定的（必须恰好使用 N 辆），还是可以使用更少辆？
- 每辆车的载重/容积上限是多少？计量单位是什么？
- 是否允许车辆空载出发？
- 车辆是否有类型区分（大车/小车、冷藏车/常温车）？不同类型能服务的网点是否不同？

### 起终点规则
- 车辆完成所有任务后是否必须返回起点（仓库/出勤站）？
- 起点是否固定（统一从仓库出发），还是可以从任意网点出发？
- 多仓库场景：每辆车是从固定仓库出发，还是可以自由选择出发仓库？

### 行驶与服务时间
- 不同路段的速度是否有区别（如干线 70 km/h、支线 35 km/h）？
- 每个网点的服务时间（停留/装卸时间）是多少？
- 是否有时间窗约束（必须在某时间段内到达）？违反时间窗是硬约束还是允许罚款？
- 当班累计行驶时间/里程是否有上限？

### 分组与隔离规则
- 城市网点和乡镇网点是否必须分车配送（不允许同车混跑）？
- 危险品是否有混装禁止规则（同类才能装同一辆车）？
- 是否有应急覆盖要求（某些节点必须被经过）？
- 同一客户的多个需求是否必须由同一辆车服务？

### 里程 / 风险约束
- 当班累计行驶里程是否有上限？
- 是否有路线风险评分，累计风险不得超过阈值？
- 是否需要强制休息（连续行驶 X km/h 后休息 Y 分钟）？

---

## 常见隐含约束

- **"有 N 辆车"≠"必须用满 N 辆"**：需确认是恰好使用还是最多使用
- **换乘里程计入总里程**：换乘/接驳过程的里程是否计入当班里程上限
- **工作量均衡软目标**：多车场景常有"各车工作量尽量均衡"的隐性要求，优先级需确认
- **评分公式**：TSP 多实例任务中，任意一个实例路线缺失通常导致该实例得分为零
- **时间窗弹性**：部分场景时间窗是软约束，违反时按延误分钟数收罚款，而非直接禁止
