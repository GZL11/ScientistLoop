# 分配与匹配类任务澄清参考

适用场景：设施选址（Facility Location）、指派问题（Assignment Problem）、二分图匹配、集合覆盖/集合划分、资源分配等。

读完数据后，将你对以下每条约束的理解整理成确认问题，逐一向用户确认，**不得因"数据已有"而跳过**。

---

## 需要确认的约束

### 优化目标
- 优化目标是最小化总成本（建设费 + 运营费 + 运输费）、最大化覆盖率，还是多目标？
- 多目标时的优先级或权重如何设定？
- 是否允许部分不满足（允许缺口但罚款），还是必须 100% 满足？

### 设施选址约束（Facility Location 场景）
- 候选设施数量是固定的（必须选恰好 K 个），还是有上/下限？
- 每个设施的容量（服务量上限）是多少？计量单位是什么？
- 开设一个设施的固定成本是多少？是否因地点不同而异？
- 每个需求点（客户）是否只能由一个设施服务（硬分配），还是可以多个设施共同服务？

### 指派约束（Assignment Problem 场景）
- 每个任务是否必须且只能分配给一个资源（一对一），还是允许一对多？
- 资源是否有容量上限（每个资源最多承接 M 个任务）？
- 是否有禁止分配组合（某资源不能执行某类任务）？
- 任务是否有优先级，高优先级任务必须优先被分配？

### 覆盖约束（Set Cover 场景）
- 覆盖的定义是什么（距离 ≤ X km、时间 ≤ Y 分钟，还是其他标准）？
- 目标是最小化所选集合数，还是在给定集合数下最大化覆盖率？
- 每个需求点是否必须被覆盖（硬约束），还是覆盖率达到某比例即可？
- 是否要求二次覆盖（至少被两个设施覆盖，以防单点失效）？

### 匹配约束（Matching 场景）
- 匹配是否必须完美（所有节点都被匹配），还是允许部分未匹配？
- 匹配是否有容量限制（一个节点可以被匹配多少次）？
- 是否有偏好约束（某些配对优先，某些配对禁止）？

### 成本结构
- 总成本的构成：固定开设成本 + 运输/分配成本，两部分如何权衡？
- 运输成本是按距离、按需求量，还是固定费率计算？
- 是否有规模经济（设施服务量越大，单位成本越低）？

## 常见隐含约束

- **容量 Capacitated**：很多选址问题是有容量限制的（CFLP），容量单位需要仔细确认（件数/重量/服务次数）
- **需求点可分割**：若允许一个需求点由多个设施服务，需确认分割的比例是否任意
- **开设成本阶梯**：某些场景设施容量可以扩建，扩建费用按阶梯收费
- **服务半径硬限制**：超出服务半径的分配被完全禁止，而不是按距离加价
- **备份覆盖要求**：应急/医疗场景常要求每个需求点被至少两个设施覆盖
