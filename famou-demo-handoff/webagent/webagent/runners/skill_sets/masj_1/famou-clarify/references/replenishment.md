# 库存与供应链类任务澄清参考

适用场景：库存补货、多供应商采购、多仓库调拨、Hub-Spoke 补货、含提前期的计划、经济批量（LOT Sizing）等。

读完数据后，将你对以下每条约束的理解整理成确认问题，逐一向用户确认，**不得因"数据已有"而跳过**。

---

## 需要确认的约束

### 优化目标
- 优化目标是最小化总成本（采购 + 库存 + 缺货惩罚）、最大化服务水平，还是多目标？
- 成本构成：固定采购成本、单位采购成本、库存持有成本、缺货罚款，分别如何计算？
- 缺货是硬约束（100% 满足）还是软约束（允许缺货但罚款）？

### 提前期
- 从下单到到货的提前期是多少？是否按 SKU / 供应商区分？
- 提前期是固定的还是有波动？
- 本周下单何时到货（下周？下下周）？是整数天还是工作日？
- 提前期内是否允许多次下单？

### 初始库存
- 计划开始时各 DC / 仓库的初始库存是多少（把你读到的数值列出来）？
- 若数据未提供，是否默认为零？
- 在途库存（已下单未到货）是否纳入初始状态？

### 容量单位
- 仓库容量的计量单位是什么（件数、冷链单元、重量、体积）？
- 订购量上限是全网共享总上限，还是每个节点独立上限？
- 是否有最小订购批量（MOQ）？

### 替代规则
- 高等级 SKU 是否可以在低等级 SKU 缺货时作为替代？
- 替代时是否产生额外成本？比例是否 1:1？
- 短保品是否也适用替代规则？

### 网络结构与调拨
- 地区仓只能从中央仓调拨，还是也可以直接向供应商采购？
- 每次调拨是否产生运输费用？
- 是否有最小批量要求（每次调拨至少 X 件）？
- 是否允许仓库之间横向调拨（同级仓之间）？

### 框架合同 / 采购约束
- 是否有框架合同（一旦启用须达到最低采购量）？
- 供应商多样性要求：整个计划期内至少使用 N 家供应商？
- 单一供应商集中度上限：不超过总量的 X%？
- 是否有长周期附加费（交货周期超过阈值时每单位额外收费）？

---

## 常见隐含约束

- **保质期 / 损耗**：短保品超期未售出会产生废弃成本，补货量不能过多
- **提前备货会挤占容量**：提前备货虽然降低缺货风险，但会占用冷链容量，影响其他品类的补货
- **库存按规格聚合**：某些场景下同规格库存合并管理，不按批次区分
- **次品率约束**：供应商加权平均次品率不超过全局上限
- **在途库存忽略风险**：遗漏在途库存会导致重复订货，计划期初库存应包含在途量
