# 补货 / 采购子族识别指南

> 表中具体数字(容量 1200、占比 40%、288 时段...)都是**示例**——说明该子族的典型样貌,
> 不是固定参数。识别时看**信号**(网络结构、是否有提前期、是否有 SOC...),
> 实际数字以用户提供的问题描述为准。

问题描述通常不会点名子族。从下面 4 个信号反推:

1. **网络结构**:独立 DC / 中央仓+地区仓 / 多供应商 → A / B / C
2. **是否有提前期** lead_time → D
3. **是否选址决策**(开关设施)→ E
4. **是否能源/SOC** → F

## 六大子族

### A. 多 DC 独立多周期补货

**信号:**
- 多个独立 DC 各自下单
- 多周期(T = 10–30 期)
- 每 DC 有容量上限
- 可能有替代品、保质期、产能上限
- 目标:采购 + 持仓 + 损耗 + 缺货 → 最小化

**典型样貌:**
- 5 DC × 3 SKU × 20 周;容量数百到数千件;保质期 4–10 周;
  全网产能上限百级到千级;高等级 SKU 替代低等级(Premium → Basic);提前期 = 0

**主算法:** PuLP + CBC,变量数 ~300 量级,秒级到 30 秒求解。

---

### B. 枢纽辐射网络补货(Hub-Spoke)

**信号:**
- 中央仓从供应商采购,再向地区仓调拨
- 调拨有运费(按量或按批次固定费)
- 中央仓容量大、地区仓容量小

**典型样貌:**
- 中央仓容量数万件,地区仓数百;调拨费 0.5/单位 量级;20 期 × 3 SKU 量级;
  只要中央仓产能充足,可以做到零损耗零缺货

**主算法:** PuLP + CBC,决策变量分两层(中央采购 + 地区调拨),库存守恒分两层写。

---

### C. 多供应商采购优化

**信号:**
- 多个候选供应商(5–10 家),各有不同价格 / 产能 / 质量 / 附加费
- 复杂成本结构:基础价 + 汇率 + 进口税 + 风险溢价 + 质检费 + 长周期附加 + 折扣
- 框架合同(启用→满足最低量)、单一占比上限、次品率上限、最少供应商数

**典型样貌:**
- 6–10 供应商、4–8 产品、3–6 月;月产能与起订量约束;次品率 ≤ 2% 量级;
  至少 N 家;单一占比 ≤ 30–40%;部分供应商有框架合同最低量

**主算法:** PuLP + CBC,二元变量 `use[s]`(启用)+ `early_pay[s,m]`(折扣),连续变量 `buy[s,p,m]`。

---

### D. 带提前期补货

**信号:**
- 明确的 `lead_time_periods`(下单后等 L 期到货)
- SKU 级别不同(不同 SKU lead_time 可能不同)
- 期初无在途,前 L 期不可避免缺货

**典型样貌:**
- 5 DC × 3 SKU × 20 周;lead_time = 2–4 周(SKU 级);shelf_life = 4–10 周;
  冷库容量数千件;高等级替代低等级

**主算法:** PuLP + CBC(精确)或滚动时域贪心(约束太复杂或规模过大时备选)。

---

### E. 容量选址(CFLP)

**信号:**
- 候选设施集 + 客户集;选哪些设施开 + 客户分配给哪个设施
- 固定开设成本 + 运输成本
- 设施容量上限

**典型样貌:**
- 选 N 个候选 DC 中的若干,客户分配到开设的设施;固定费量级远高于运费

**主算法:** PuLP + CBC,二元变量 `open[f]`、`assign[c, f]`。

---

### F. 储能 / 能源调度

**信号:**
- 储能电池(SOC 范围、充放电效率)+ 光伏 / 风电 + 电网
- 分时电价(ToU)
- 5 分钟或 15 分钟粒度,288 / 96 时段
- 目标:最小化购电成本 + 自发电成本 + 充放电切换次数

**典型样貌:**
- 千 kWh 级电池、kW 级最大充放、SOC 5–95%、效率 95%/95%、288 时段、
  ToU 谷/平/峰三档电价

**主算法:** PuLP + CBC,连续变量 + 二元(充放电状态、切换计数),秒级求解。

---

## 快速判断决策树

```
有 SOC / 储能 / 分时电价?
  YES → F(能源调度)
  NO ↓

有"开/关设施"决策?
  YES → E(CFLP)
  NO ↓

有多家供应商 + 复杂定价?
  YES → C(多供应商采购)
  NO ↓

有中央仓 → 地区仓两层调拨?
  YES → B(Hub-Spoke)
  NO ↓

有 lead_time 提前期?
  YES → D(带提前期)
  NO → A(多 DC 独立补货)
```

## 成本结构速查

| 成本项 | 适用子族 | 建模 |
|--------|---------|------|
| 采购 | A/B/C/D | 单价 × 订购量 |
| 持仓 | A/B/D | 单价 × 期末库存 |
| 损耗/报废 | A/B/D(保质期)| 单价 × 过期量 |
| 缺货 | A/B/D | 单价 × 未满足量 |
| 调拨运费 | B | 单价 × 调拨量 / 固定费 × 启用 |
| 汇率 + 进口税 + 长周期 + 风险 + 质检 | C | 复合单位成本 |
| 折扣(提前付款)| C | -折扣 × 二元启用(双线性需线性化) |
| 设施固定费 | E | 固定 × 开设二元 |
| 运输费 | E | 单价 × 分配 × 距离 |
| 购电费 | F | ToU 单价 × 时段电量 |
| 自发电费 | F | 单价 × 出力电量 |
| 切换罚款 | F | 单位罚款 × 切换次数 |

## 替代规则方向(高频踩坑点)

通常是**高等级 SKU 替代低等级 SKU**(Premium → Basic),不要建反。

替代变量进出方向以"哪一类被替代了"为锚点:

- 低等级 SKU 缺货 → 用高等级 SKU 库存补
- 在低等级守恒方程中"+ 替代入" `sub_in[low, t]`
- 在高等级守恒方程中"- 替代出" `sub_out[high, t]`
- 等量配对:`sub_in[low, t] == sub_out[high, t]`

错误形式:`sub_in[basic] == sub_out[basic]`(自己替自己,荒唐但常见)。

## 网络规模 vs 算法

| 变量数 | 推荐 | 时间 |
|-------|------|------|
| < 500 | PuLP+CBC, gap 0.001 | < 30s |
| 500–5000 | PuLP+CBC, gap 0.005 | 30–240s |
| > 5000 | 滚动时域 / 分解(按 SKU 或按 DC)| 视实现 |

## 子族 vs 主算法 vs 特殊点速查

| 子族 | 主算法 | 特殊点 |
|---|---|---|
| A 多 DC 独立 | MILP | 替代方向、保质期、产能 |
| B Hub-Spoke | MILP | 中央 + 地区两层守恒 |
| C 多供应商 | MILP | 复杂定价、合同、占比、次品率、双线性线性化 |
| D 带提前期 | MILP | per-SKU lead_time、前期必缺货 |
| E CFLP | MILP | 开设二元 + 分配二元 |
| F 储能 | MILP | SOC、ToU、切换计数 |
