## 二、真正的竞对：四家

从上面二十多家里收窄。判据是**技术机制重合**，不是「都叫 AI for Science」。

### ① Sakana AI —— 逐条对应我们的 loop（日本，$2.65B）

| Sakana                                                                                                                                    | 我们                                                      |
| ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| **Darwin Gödel Machine**：自改代码 + 不断扩张的变体**谱系存档** + 从存档选节点自修改                                         | **演化图 v2**：多父 DAG + 节点带分数 + 从前沿选节点 |
| **ShinkaEvolve**：island 间知识迁移存档、novelty 拒绝采样、bandit 式 LLM 集成、**meta-agent 把洞见合成建议追加进变异 prompt** | **Cross-task ExpBank** + 四段自足索引表             |
| AI Scientist v1/v2（agentic tree search 自动出论文）                                                                                      | famou-scientist 主线                                      |
| ALE-Bench                                                                                                                                 | NatureBench / ACGBenchmark / TBS                          |

**要害：它把这些全开源了**（ShinkaEvolve 是 Apache-2.0，含实现细节和可视化工具）。对我们是双向的 —— 挡住了我们独占，也把它们变成了谁都能用的公共先验。

### ② Weco AI —— 最小但最正面对撞（英国，$8M）

AIDE 的产品定义几乎是我们 loop 的同一句话：「你指给它代码和评测，它提改动、跑你的指标、留下赢的、循环」。用户场景明确包括 **agent harness、prompt、ML pipeline、GPU kernel**。成绩硬：o1-preview + AIDE 在 MLE-Bench 上 medal rate 涨 5 倍；**RE-Bench 上首个超过顶尖人类研究员的自主系统**。

**要害：体量只有我们一个零头，但方向最像。** 融资少 → 大概率没有专利和市场预算 → 这是机会窗，不是威胁。

### ③ 深势科技 —— 国内最直接对标（C 轮 >8 亿元）

文献 + 计算 + 实验 + 智能体全栈，和我们的产品形态几乎一一对应，且**政策顺风**：2025-08 国务院《关于深入实施「人工智能+」行动的意见》把「人工智能+科学研究」放在首位。

### ④ 晶泰科技 —— 唯一盈利的（港股上市）

Multi-Agent 当「智能项目经理」自主拆解研发目标、调度全流程资源 —— **这跟我们 loop 的控制面是同一件事**。而且它已经跑通了商业闭环（2025 营收翻三倍、盈利），还拿了国家科技重大专项的科学智能体平台课题。

> **对外口径提醒**：SciMaster 这类「6 小时≈博士 1–3 个月」的说法会成为汇报时的隐性基准线。建议我们对外的数字一律绑死可复跑的 benchmark，不做同类比喻 —— 比不过，也不该这么比。

## 三、与我们相关的五个方向

| 方向                                      | 现在什么状况                                                                                                                                                               | 谁在里面                                                               | 我们的位置                                                                                           |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **LLM + 演化搜索 / 算法发现**       | **最拥挤，也最成熟**。Google 从论文到产品到客户全通了；开源复现三家（OpenEvolve / ShinkaEvolve / CodeEvolve）                                                        | Google DeepMind、Sakana、Weco                                          | **正面战场**。不可能靠「做演化搜索」差异化，只能靠工程机制                                     |
| **LLM + 组合优化 / 启发式设计**     | **学术满天飞、商业刚起步**。EoH / ReEvo / LLaMEA / HeurAgenix 等一堆论文，但产品化才刚开始                                                                           | Gurobi（2026-07 Intelligence Hub）、被收购的 Quantagonia；大厂基本没进 | **最明显的机会方向**。在位厂商刚动，创业公司稀少                                               |
| **AI4AI（AutoML / ML 工程 agent）** | 被大厂占得最严实（NAS 专利族从 2017 堆到现在，全是 Google 系）；创业侧只有 Weco 一家像样                                                                                   | Google、IBM、Weco                                                      | 技术上和我们最近，但**上游被堵**。适合作为能力而非独立产品                                     |
| **AI4Science**                      | **钱最多、执行最落后**。Lila 的实验室近期探访基本是空的、正在搬场地；Periodic 刚开始搭 SF 实验室，先手工合成、高通量机器人还在路线图上；PitchBook 在质疑 VC 回报路径 | Lila、Periodic、Edison、CuspAI、深势、晶泰、深度原理                   | **窗口没有看上去那么窄**。但「能做科研」已经被 Google 拿去卖了，我们的差异化必须落在搜索机制上 |
| **RSI / 自演化 agent**              | **学术 2025–2026 井喷、资本疯抢、工程几乎空白**。DGM、Gödel Agent、STOP、AgentSquare、GENOME，外加普林斯顿/清华/上交的综述                                         | Sakana、Recursive、Ricursive、Prime Intellect                          | **第二个机会方向**，但窗口最短 —— 开源速度远快于任何人建壁垒的速度                           |
