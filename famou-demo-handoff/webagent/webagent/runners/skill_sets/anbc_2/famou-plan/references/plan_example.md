# PLAN.md 格式示例

以下是一个生产排程场景的完整示例，展示 PLAN.md 应有的信息密度和写法。

---

```markdown
# 任务：5月第一周生产排程

## 背景

### 业务场景
用户为生产计划员，希望在本周内完成所有订单且尽量不延期。

### 数据文件清单
- orders.csv（47 条订单，关键字段：订单号、产品族、工序时长×3、交货期、优先级）
- machines.csv（8 台机器，关键字段：机器ID、所属工序类型、产能）

### 数据结构说明
- 优先级字段（priority）：1=VIP，2=普通
- 工序时长字段为 3 列（工序1/2/3 的时长，分钟），三道工序必须按序进行

### 澄清结论摘要
- 不安排夜班、周末不生产
- 换型时间未提供，默认 15 分钟
- 优先级字段为空的订单视为普通订单

## 目标
主目标：最小化延期订单数量（tardiness = 0 的订单数最大化）
次要目标（按优先级）：
1. 最小化最大延期时长
2. 最大化设备利用率均衡度

成功标准：延期订单 ≤ 5 条，或相较当前手工排程延期减少 30% 以上。

## 约束条件（违反则结果无效）
### 硬约束
- 每台机器同一时刻只能处理一个订单
- 工序顺序不可颠倒（工序1 → 工序2 → 工序3）
- 每日生产窗口 08:00–18:00，不安排夜班
- 周末（周六、周日）不生产
- VIP 订单（priority=1）不得延期

### 软约束
- 同一产品族的订单尽量集中排产，减少换型次数
- 设备利用率尽量均衡，避免单机过载

## 可视化规格
图表类型：横向甘特图（机器为纵轴，时间为横轴）
选择理由：排程结果最直观的呈现方式，符合计划员日常使用习惯
核心展示要素：
- 每个 bar 代表一个订单，颜色按优先级（红=VIP，蓝=普通）
- 延期订单用虚线边框标注
- X 轴显示日期+小时刻度
交互要求：悬停显示订单号、工序、时长、交货期；支持按机器筛选

## 必须交付的产物
- [ ] 排程结果表：包含每条订单的开始时间、结束时间、所用机器、是否延期，CSV 格式，列名用中文
- [ ] 延期分析摘要：列出所有延期订单及延期时长，文字说明延期原因（瓶颈机器 / 交期过紧）
- [ ] 可视化甘特图：展示所有机器的排程时间线，颜色区分订单优先级，标注延期订单，html 格式，支持缩放和悬停查看订单详情

## 所用默认值
- 换型时间：未提供，默认 15 分钟
- 周末是否生产：未确认，默认不生产（仅工作日）
- 优先级字段为空的订单：默认视为普通订单（priority=2）
```
