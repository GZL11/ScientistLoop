> **Owner**: 刘丹宇

> **参考实现**: `demo/static/index.html` runDeepResearch()、`demo/server.py` system_prompt

---

## 1. 功能定位

用户输入一个研究问题，Agent 自主完成文献调研，产出结构化报告 + 来源列表 + 启发式追问。

**是**：

- 用户主动触发的调研任务（点击"深度研究"按钮）
- Agent 自主执行 3 步流程（文献检索 → 精读分析 → 综合报告）
- 产物：Markdown 报告 + BibTeX 引用 + 精读笔记

**不是**：

- 不是问答（不是一问一答，而是 Agent 自主执行多步调研）
- 不是论文写作（产物是调研报告，不是可投稿论文）
- 不是 AutoResearch（不写代码、不跑实验）

---

## 2. 用户旅程

```
① 用户点击"深度研究"按钮（工具栏高亮）
      │
      ▼
② 用户输入研究主题并发送
      │
      ▼
③ LLM 返回 Plan Card（标题 + 3~6 步骤 + 编辑/取消/开始）
      │ 用户点"开始"
      ▼
④ Agent 自主执行 3 阶段
   · 文献检索 → 右侧面板逐篇添加论文卡片
   · 精读分析 → 提取关键结论（带引用标记）
   · 综合报告 → 左侧流式输出 Markdown 报告
      │
      ▼
⑤ 产物生成 + 启发式追问
   · 实验台生成 3 个文件（报告/BibTeX/笔记）
   · 聊天区底部出现 3 条追问按钮
```

---

## 3. 触发与意图路由

### 3.1 触发方式

点击工具栏"深度研究"按钮 → 输入框 placeholder 变为"输入你想调研的主题..."→ 发送消息。

### 3.2 Plan Card 生成

前端调用 `callSessionLLM()`（千帆直连），system prompt 要求 LLM 输出 JSON 计划块：

```json
{
  "intent": "deep_research",
  "title": "简短标题",
  "steps": [
    {"title": "步骤标题", "description": "具体描述"},
    ...
  ]
}
```

前端解析 JSON 后调用 `renderPlanCard()` 渲染。

### 3.3 Plan Card 交互

| 状态   | 按钮               | 行为                                                           |
| ------ | ------------------ | -------------------------------------------------------------- |
| 未开始 | 编辑 / 取消 / 开始 | 编辑→聚焦输入框让用户自然语言调整；取消→移除卡片；开始→执行 |
| 运行中 | 更新               | 底部显示状态文字 + 进度条 + ■ 暂停按钮                        |
| 完成   | —                 | 进度 100%，暂停按钮隐藏                                        |

---

### 4. 产物生成

执行完成后自动生成 3 个产物文件到实验台：

| 文件                        | 内容                    |
| --------------------------- | ----------------------- |
| `deep_research_report.md` | 完整研究报告            |
| `references.bib`          | BibTeX 引用（N 篇文献） |

## 6. 界面表现

### 6.1 右侧面板

右侧面板始终为两个 Tab：**文献** | **实验台**（无"轨迹" Tab）。

Deep Research 执行时：
- 默认激活"文献" Tab
- 文献 Tab 标题旁显示统计 badge（`N 片段 · M 文献`）
- 顶部摘要行："文献列表 · N 篇文献"
- 底部（`rpFooter`）：进度条 + 运行时间 + Token 用量

执行完成后：
- 实验台 Tab 新增 3 个产物卡片（报告 / BibTeX / 精读笔记）

### 6.2 文献卡片

`addSource()` 逐篇添加，每张卡片包含：

- 编号圆点（绿色底 `#0d7c66`）+ 论文标题
- 精读/扫描 badge（精读=绿底，扫描=灰底）
- 作者 · 期刊（灰色小字）
- 添加到知识库按钮（文件夹 icon → KB 选择 dropdown）
- 摘要片段（默认折叠，点击展开）

### 6.3 引用交互

报告正文中 `[1]` `[2]` 通过正则替换渲染为绿色上标 `<sup class="cite-num">`：

- 点击 → 切到文献 Tab → 滚动到对应卡片（`scrollIntoView`）→ 高亮闪烁 2 秒
- 自动展开该卡片的第一个摘要片段
- 文献列表在报告生成前已加载完毕，流式输出时引用即可交互

## 7. 暂停与打断

- ■ 暂停按钮：停止后续 LLM 调用，状态变"已暂停"
- 用户可在输入框继续对话或调整方向
- 内部通过 `drStopped` 标志在每个阶段间检查

---

## 8. 后端协议

### 8.1 LLM 调用链路

Deep Research 全程使用**千帆直连**（不走 WebAgent），通过 `callSessionLLM()` → Flask `/api/sessions/<sid>/send` → qianfan OpenAI 兼容接口。

### 8.2 调用序列

| 序号 | 目的       | 输入                       | 输出                       |
| ---- | ---------- | -------------------------- | -------------------------- |
| 1    | 文献检索   | 研究主题                   | 5 篇论文列表（纯文本，`    |
| 2    | 精读分析   | 主题 + 文献列表            | 结构化分析（带引用标记）   |
| 3    | 综合报告   | 主题 + 精读分析 + 文献列表 | 完整 Markdown 报告（流式） |
| 4    | 启发式追问 | 报告摘要（前 800 字）      | 3 行问题文本               |

每次调用独立，无多轮对话 context 累积。

---

## 9. 与普通对话的区别

| 维度      | 普通对话       | Deep Research          |
| --------- | -------------- | ---------------------- |
| 触发      | 直接发消息     | 先点"深度研究"按钮     |
| Plan Card | 无（直接回复） | 有（需确认）           |
| LLM 调用  | 1 次           | 4 次串行               |
| 右侧面板  | 不变           | 切到文献 Tab，隐藏轨迹 |
| 产物      | 无             | 3 个文件               |
| 追问      | 无             | 3 条启发式追问按钮     |
