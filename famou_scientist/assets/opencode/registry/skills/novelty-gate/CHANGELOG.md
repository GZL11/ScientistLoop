# Novelty Gate Skill Changelog

## 20260718-001-overlap-improvement-gate

- Replace the old "novel enough / incremental / repetitive" gate with overlap-aware decisions.
- Add `OPEN GAP`, `IMPROVABLE BASELINE`, `OVERLAP BUT DIFFERENT`, `INCREMENTAL`, and `DUPLICATE`.
- Require targeted literature checks before presenting an idea.
- Require competing papers, overlap matrix, improvement opportunity, compute/time/data cost, confidence, and go/revise/reject.
- Clarify that related work is not automatic rejection; only direct duplication should be discarded.
