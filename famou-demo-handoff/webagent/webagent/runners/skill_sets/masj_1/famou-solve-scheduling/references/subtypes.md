# 排程子族识别指南

> 本文件中的具体数字(任务数、产线数、机器数...)都是**典型样貌**——
> 说明该子族常见的规模与约束量级,不是固定参数。
> 实际数字以用户提供的问题描述为准。

问题描述通常没有明示子族。从**数据实体结构**和**目标函数**反推。
拿不准时倾向于"硬约束更复杂"的那一类——漏建模约束比过度建模代价大得多。

## 三大子族

### A. 单机 / 单跑道 / 序列优化(Sequencing)

**信号(满足任一即定型 A):**
- 仅一个处理资源(一条跑道、一台机器、一条主线)
- 任务之间存在**间隔矩阵 / 分离矩阵**(separation matrix),或顺序固定的工序串
- 目标聚焦"序列质量":早晚惩罚、加权完成时间、makespan
- 任务规模 50–1000+,没有多资源容量约束

**典型样貌:**
- 数百架飞机,N×N 分离矩阵,目标早晚惩罚最小(单跑道排序)
- 流水车间:多机但顺序固定,目标 makespan
- 作业车间:多机+任意工序顺序,目标 makespan
- 钢卷/板材切排:**先识别为 A 类**(单台切机的工件序列),切排几何由专门 packing 库(rectpack)处理

**主算法:** ILS(Iterated Local Search)+ numpy 向量化评估;
作业车间用 Tabu Search(针对每机器工序的邻域)。

---

### B. 多产线 / 多工序生产排程(Multi-line Production)

**信号:**
- 多条产线/工序(典型 2–10 条),多产品,**每产线每天一种产品**
- 有**换产成本/时间**(同类换产 ≠ 跨类换产);可能叠加:夜班、外包、冷却期、保质期
- 目标是**加权总成本**(换产费 + 逾期罚款 + 外包费 + 库存持有 + 夜班费)
- 周期通常 ≤ 30 天,决策变量数适合全局 MILP

**典型样貌:**
- 3 产线 × 7 天,A/B/C 类换产费数百到数千元;夜班 ×1.5 产能 + X 元/吨;
  A↔C 冷却期 1–2 天;保质期 4–10 天;Gold/Silver 客户罚款差 3×;
  外包 X 元/吨 上限若干吨/天
- 多周期 + 人力班次 + 库存持有
- 大规模(数百工单 × 数十机台 × 数百模具):**数据格式可能特殊**(pickle + 自定义模块),
  规模大时切到启发式贪心 + 反向排程

**主算法:** PuLP + CBC(小规模 ≤ 50 决策周期);规模大时切 OR-Tools CP-SAT 或贪心 + 局部搜索。

---

### C. 资源约束项目 / 人员排班(Resource-Constrained)

**信号:**
- 多种**硬性资源池**(手术室、ICU 床、护士、岸桥、设备、医生、机组司机),各有日上限或时段上限
- 任务有**前序约束**(precedence)或**闭合路径**(首站=末站)
- 目标可能是:资源数最少(岸桥/司机)、工期最短、综合罚款最小
- 任务规模差异大:30–500

**典型样貌:**
- 数十台岸桥 × 数十艘船:最小化岸桥使用总数,连续岸桥块,移动开销
- 数十台手术 × 多类资源约束(房型匹配、医生上限、特定设备每日上限、ICU 床跨 2 天、感控排当日最后、护士工时、precedence、加班费、延迟罚款)
- 数百任务 × 几个站点:最小化司机数,**闭合路径硬约束**(首站=末站),工时上限,里程上限,换乘衔接(≥ 5 + 换乘分钟)
- 项目工期:严格顺序链 + 容量约束

**主算法:**
- 任务 < 50 / 资源结构简单 → MILP 或 CP-SAT,全局最优可达
- 50–200 任务、多硬资源 → **CP-SAT 优先**(NoOverlap + Cumulative 约束建模简洁)
- > 200 任务、含位置/闭合约束(机组排班)→ 贪心链构造 + 模板枚举 + 局部修复

## 快速判断决策树

```
是否仅有 1 个处理资源 / 顺序矩阵 / 工序链?
  YES → A(单机序列 / Flow shop / Job shop / Cutting-Nesting)
  NO ↓

是否多产线 + 换产成本 + 多周期成本权衡?
  YES → B(多产线生产排程)
  NO ↓

是否多硬资源池 + 前序/闭合约束 + 资源数最小化目标?
  YES → C(资源约束 / 人员排班)
```

## 混合情形决策

| 场景 | 主导特征 | 归类 | 备注 |
|------|---------|------|------|
| 工单 + 模具 + 机台分配 | 多产线 + 资源 | B(带模具变量) | 规模大切启发式贪心 |
| 资源最少 + 物理位置 | 多资源池 + 位置 | C | 算法用贪心,**不用** MILP |
| 序列 + 几何排布(切排) | 单机序列 | A + 切排几何 | 切排用 rectpack 库 |

## 子族 vs 主算法 vs 时间预算速查

| 子族 / 形态 | 推荐主算法 | 时间预算 |
|------|-----------|---------|
| A 单跑道 / 序列 / 早晚惩罚 | ILS(swap+or-opt+扰动)| ILS 全程 270s |
| A 流水车间 makespan | NEH 启发式 + ILS | 270s |
| A 作业车间 | Tabu Search | 270s |
| A 切排几何 | rectpack + 序列调优 | 240s |
| B 多产线 + 换产 | MILP CBC + 手工初始解 | CBC 240s + 验证 |
| B 多周期 + 人力 + 库存 | MILP CBC | CBC 200s |
| B 大规模工单 + 模具 | 贪心 EDD + 反向排 | 240s |
| C 多资源 + NoOverlap | CP-SAT | 240s |
| C 资源最少 + 位置约束 | 按区贪心 + 时间冲突修复 | 60s 级 |
| C 闭合路径 + 换乘 | 贪心链 + 闭合检查 | 120s |
| C 严格顺序链 + 容量 | MILP CBC(小规模)| CBC 180s |

## 规模 vs 时间预算

| 任务数 / 资源数 | 推荐 | 典型耗时 |
|----------------|------|---------|
| < 50 / 简单 | MILP / CP-SAT | < 30s |
| 50–200 / 多资源 | CP-SAT、CBC(gap 0.5%)| 120–240s |
| 200–500 / 物理约束 | 贪心+图匹配+模板枚举 | 60–120s |
| > 500 | 元启发式(ILS / SA / Tabu)| 240–280s |
