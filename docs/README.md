# Famou Scientist Docs

This directory is organized by reader intent:

- `overview/`: high-level architecture and codebase walkthroughs.
- `design/`: product, agent, benchmark, plugin, and loop design documents.
- `operations/`: runtime lifecycle, observability, and troubleshooting notes.
- `literature/`: literature retrieval, research workflow, and citation graph notes.
- `benchmarks/`: benchmark surveys, benchmark integration notes, and run results.
- `multitenant/`: multi-tenant web service design, deployment assets, and user guide.
