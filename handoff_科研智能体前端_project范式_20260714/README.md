## 2. 改了什么（功能清单）

### 2.1 Project first：落地页 + 项目为组织单元
- **一进来是「全部项目」落地页**（不再直接进散聊），首次访问必落此页（`localStorage.famou.seenHome` 控制）。
- 落地页 = 项目卡片网格（三列）+ 大「＋新建项目」卡 + 「未归档对话」卡 + 右上「临时对话」。
- **新建/删除/重命名项目只在落地页做**（唯一管理入口）。

### 2.2 侧栏：项目切换器（只切不新建）
- 侧栏顶部「当前项目 ▾」切换器：下拉 = 「⊞ 全部项目·新建/管理」+ 各项目 + 未归档对话。
- **切换器只做快速切换，不新建**（想新建 → 点「全部项目」回落地页）。
- 「知识库」→ 改名 **「文献库」**；**「资产」入口已删**；MoonLog 保留。
- 「新对话」→ 改名 **「新会话」**（进项目后才显示，落地页不显示）。

### 2.3 Session 归属 project（不再全局）
- session 属于某个项目，侧栏只显示当前项目的 session（切项目换一批）。
- 新建会话默认归当前项目；无项目上下文时归**内置「未归档对话」项目**（`UNARCHIVED`）。
- 未归档对话里的 session 可 **「↗ 移入项目」** 升级。

### 2.4 新建项目弹窗（含上传，纯前端体验）
- 命名（必填）+ 上传文件/文件夹（点选/拖拽/选文件夹）+ 创建。
- 上传的文件名存进 `projFiles`（前端演示），**真实上传落 workspace 需接后端**。

### 2.5 文献库：按项目分组
- 文献库 = 收藏/上传的**论文**（只限论文类，jpg/数据/代码不进），按「所属项目」分组。
- 数据 = `starred`（收藏文献，已有）+ **`paperProj`（新增，文献→项目归属映射）**。
- 收藏文献时记归属（归当前项目）；「上传文献」传 PDF → 建条目入库、归当前项目。

### 2.6 文献引用联动（深度研究报告 ↔ 文献）
- 报告正文 `[n]` → 渲染成可点上标 → 点击跳右栏对应文献、高亮滚动、自动展开分组。
- 文献卡加全局序号 `[n]` + 「引用片段」可展开。
- ⚠️ **依赖算法契约**（见 §4）：agent 需在正文输出 `[n]`、文献带结构化字段与引用片段。

## 3. 新增数据结构（都存 localStorage，纯前端）

| key | 内容 | 说明 |
| --- | --- | --- |
| `famou.projects` | `[{id, name}]` | 项目列表 |
| `famou.sessProj` | `{sessionId: projectId}` | 会话→项目归属 |
| `famou.curProj` | `projectId` | 当前项目（`__unarchived__`=未归档） |
| `famou.paperProj` | `{paperKey: projectId}` | 文献→项目归属 |
| `famou.projFiles` | `{projectId: [文件名]}` | 新建时上传的文件（前端演示） |
| `famou.seenHome` | `"1"` | 是否见过落地页（控制首次落地） |

内置常量 `UNARCHIVED = "__unarchived__"`（未归档对话项目 id）。

## 4. 需要算法配合的部分 ⚠️

### 4.1 上传文件真正落 workspace（当前前端只存文件名）
- 新建项目弹窗、文献库上传 = 前端选取体验，**没真上传**。需后端提供上传端点，把文件落项目 workspace。

### 4.2 文献引用联动的契约（详见 `prd/PRD_文献引用_深度研究_20260712.md`）
前端已做「`[n]` 可点 + 跳转 + 引用片段展示」，但需要 agent 侧产出：
- **C1**：报告正文引用处输出 `[n]`，n = 该文献在列表中的全局序号
- **C2**：`arc_search_literature` 输出结构化字段（title/authors/year/doi）
- **C3**：每处引用附「被引用的原文片段」（挂在 `paper.citations`）
- **C4**：编号在一次报告内稳定

### 4.3 workspace 树的组织
- 前端只展示 workspace 目录树（现状已有），**session 产出的文件落哪个子目录由 agent 决定**，前端不管。

### 4.4 project 层是否要后端化
- 当前 project 是纯前端 localStorage 分组，够做导航/归类。若要真正的「项目=独立 workspace 目录、session 建在项目目录下」，需后端支持（PRD D2/D11 有讨论，本期未做）。

- **1_项目入口与落地页**：落地页/新建项目弹窗/切换器/移入项目/删除重命名，全链路可点

### 5.2 跑真前端
```bash
cd <web目录>   # 放入改好的 src/
# 纯前端（能看 UI，不能真对话，需 CDN 拉 Babel/React）：
PORT=4203 node server.mjs   # 开 http://localhost:4203
# 完整（能真对话，需 opencode 后端）：
famou-scientist web
```
⚠️ 纯前端跑时，主区对话会「fetch failed」——那是 `/oc/*` 连不上 opencode 后端(:4097)，**属正常**，UI/导航不受影响。
