Webagent

webagent专项agent相关代码

模块说明
---
* **webagent/benchmark/** — Famou-Bench 统一评测用例集（26 个 case，覆盖优化与预测），详见 [webagent/benchmark/README.md](webagent/benchmark/README.md)
* **webagent/runners/** — Famou-Bench 评测运行框架（Runner、Evaluator、Trace Viewer、Interactive Chat 等），详见 [webagent/runners/README.md](webagent/runners/README.md)
* **webagent/loop/** — 多轮自动优化框架（Inner Agent 产出解 → Evaluator 评估 → Meta Agent 诊断 → 下一轮），详见 [webagent/loop/README.md](webagent/loop/README.md)
